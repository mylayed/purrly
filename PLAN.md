# 🐱 Purrly — план розробки

Мобільний застосунок-щоденник для власників котів: здоров'я, харчування, нагадування та AI-«настрій» кота за фото з підписами для сторіз.

- Джерело: [Notion — Purrly, котячий щоденник](https://app.notion.com/p/3ff0e16f84658180acdbd339140feec4)
- Макети (світла й темна теми): [Purrly — макети](https://claude.ai/artifact/XPvNfEY7nY1YSJqiiTcCSs)
- Складено: 2026-10-20

---

## 1. Ключові рішення

| Область             | Рішення                                                                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| Платформа           | React Native: **Expo + TypeScript + Expo Router**                                                                                   |
| Стан і дані         | Zustand (локальний стан UI) + TanStack Query (серверні дані, кеш)                                                                   |
| Бекенд              | **Supabase**: Postgres, Auth, Storage (фото й документи), Edge Functions, Realtime                                                  |
| Авторизація         | Supabase Auth + Google Sign-In + Sign in with Apple (обов'язково для App Store, якщо є Google)                                      |
| Локалізація         | i18next + react-i18next + expo-localization; JSON-файли; 🇺🇦 uk (основна), 🇬🇧 en (fallback), 🇵🇱 pl, 🇩🇪 de, 🇪🇸 es. **Без російської** |
| Push                | expo-notifications (локальні + серверні)                                                                                            |
| AI                  | Vision-модель тільки через Edge Function — ключі API ніколи не потрапляють у клієнт                                                 |
| Підписки            | RevenueCat                                                                                                                          |
| Аналітика й помилки | PostHog + Sentry                                                                                                                    |
| UI                  | Власна дизайн-система, світла/темна теми, Reanimated для мікроанімацій                                                              |
| Шрифт / іконки      | Nunito або Manrope (повна кирилиця) / один контурний набір — Tabler або Phosphor                                                    |

```
│   ├── theme/                # токени кольорів, радіуси, типографіка, ThemeProvider
│   ├── i18n/
│   │   ├── index.ts
│   │   └── locales/{uk,en,pl,de,es}.json
│   ├── stores/               # Zustand
│   ├── api/                  # Supabase-клієнт, запити TanStack Query
│   ├── features/             # weight, meals, vet, reminders, feed, mood…
│   └── lib/                  # дати, одиниці (кг/фунти), вік кота

│   ├── migrations/           # SQL-схема + RLS
│   └── functions/            # Edge Functions: ai-mood, delete-account, export-data…
└── web/sitter/               # (v2) легка веб-сторінка пет-сітера
```

## 3. Дизайн-токени

Стиль «затишний і теплий»: м'які округлі картки, мінімум тіней, глибина через відтінки фону, один теплий персиковий акцент.

| Токен                | Світла                               | Темна     |
| -------------------- | ------------------------------------ | --------- |
| `bg`                 | `#FBF7F2`                            | `#17151A` |
| `card`               | `#FFFFFF`                            | `#252129` |
| `accent`             | `#E8875B`                            | `#F09A6E` |
| `onAccent`           | `#2A1408`                            | `#2A1408` |
| `secondary`          | `#7FB59A`                            | `#8CC7A9` |
| `secondaryBg`        | `#DCEFE4`                            | `#1F3A2E` |
| `secondaryText`      | `#2F6B4F`                            | `#A8DDBF` |
| `text`               | `#2B2522`                            | `#F3EEE8` |
| `textMuted`          | `#6F655E`                            | `#A69EAB` |
| `warning` / `danger` | м'який жовтий / приглушений червоний | ті самі   |

- Радіуси карток 16–20 px, кнопки-пілюлі.
- Тема за замовчуванням — системна; перемикач Системна / Світла / Темна в кабінеті.
- Котячі деталі дозовано: лапки, вушка на аватарі, хвостик у лоадері; кіт моргає на порожніх екранах, конфеті на ачівках, легка вібрація на позначках.

## 4. Схема бази даних

### MVP

| Таблиця            | Призначення                                                                                            |
| ------------------ | ------------------------------------------------------------------------------------------------------ |
| `profiles`         | ім'я, аватар, мова, тема, одиниці (кг/фунти), статус Plus                                              |
| `cats`             | ім'я, фото, порода, дата народження, стать, стерилізація, чип, архівний прапорець                      |
| `cat_members`      | кіт ↔ користувач, роль `owner` / `family` (закладаємо з першого дня, навіть якщо спільний доступ — v2) |
| `weights`          | кіт, дата, вага, автор                                                                                 |
| `meals`            | корм, порція, час, автор                                                                               |
| `feeding_schedule` | графік годування кота                                                                                  |
| `vet_events`       | тип (щеплення / обробка від паразитів / візит), дата, наступна дата, нотатки                           |
| `litter_events`    | позначки лотка (для лоток-трекера)                                                                     |
| `reminders`        | тип, розклад, прив'язка до кота/події, стан виконання                                                  |
| `photos`           | стрічка «день із життя», шлях у Storage, AI-настрій, підпис                                            |
| `notes`            | текстові нотатки                                                                                       |
| `ai_usage`         | лічильник AI-запитів для лімітів Free-тарифу                                                           |

### Закладено на v2

| Таблиця        | Призначення                                       |
| -------------- | ------------------------------------------------- |
| `documents`    | файли з клініки з датою й тегом                   |
| `lab_results`  | показник, значення, одиниця, норма, дата, джерело |
| `sitter_links` | випадковий токен, дати дії, дозволи               |

**RLS:** до будь-яких даних кота мають доступ лише його учасники з `cat_members`. Видаляти кота й керувати доступом може тільки `owner`. Кожен запис зберігає автора (`created_by`).

## 5. Етапи розробки

### Етап 1 — Підготовка (1 тиждень)

- [ ] Фінальна назва; перевірити домени та назву в App Store і Google Play
- [ ] Подати заявку в Apple Small Business Program
- [ ] Список екранів і користувацькі сценарії
- [ ] Дизайн у Figma: онбординг, головна, профіль кота, кабінет (на основі макетів)
- [ ] Схема бази даних (розділ 4)

**Готово, коли:** затверджені назва, список екранів, макети ключових екранів і схема БД.

### Етап 2 — Основа (1–2 тижні)

- [x] Ініціалізація Expo-проєкту (SDK 58, TypeScript, Expo Router, маршрути в `src/app/`)
- [x] ESLint (eslint-config-expo) + Prettier
- [x] Структура папок
- [x] Дизайн-система: токени, ThemeProvider (Системна / Світла / Темна), базові компоненти, шрифт Nunito
- [x] i18n: uk + en, автовизначення мови пристрою, fallback на en
- [x] Supabase: проєкт, міграції таблиць, RLS-політики, бакети Storage
- [ ] Авторизація: email + пароль ✅, Google ✅ (web; Android — після dev build і Android-клієнта), Apple — код готовий, після акаунта Apple Developer
- [x] Особистий кабінет: профіль (ім'я, аватар, мова, тема, одиниці); налаштування сповіщень — разом із push на етапі 3
- [x] Конфіденційність: експорт даних (JSON) і видалення акаунта (Edge Function `delete-account`) — обов'язково для обох сторів
- [ ] Sentry і PostHog підключені з першого білда

**Готово, коли:** можна увійти через Google/Apple, змінити мову й тему, видалити акаунт; RLS не пускає до чужих даних.

### Етап 3 — Функції MVP (3–4 тижні)

- [x] Профіль кота: ім'я, фото, порода, дата народження, стать, стерилізація, чип; «Кіт у людських роках»
- [x] Кілька котів в одному акаунті: додати / редагувати / архівувати / видалити (ліміт 1 кота для Free — разом із paywall на етапі 5)
- [x] Вага: записи + графік динаміки (кг/фунти, зміна за місяць, сигнал при схудненні від 5 % / 10 %)
- [x] Харчування: корми, порції, графік годування (відмітка одним дотиком, журнал за 30 днів, ккал за калорійністю корму)
- [x] Ветеринарія: щеплення, обробки від паразитів, візити (дата «наступного разу», «найближче» з простроченим і «скоро»)
- [x] Лоток-трекер: позначка одним тапом прямо з профілю кота, тиждень у таблиці
- [x] Нагадування (push): корм, ліки, щеплення, наступний візит — без спаму, групування (локальні сповіщення на телефоні; серверні push для сім'ї — разом зі спільним доступом)
- [x] Нотатки та фото-стрічка «день із життя»
- [x] Порожні стани з ілюстраціями та анімацією (кіт, що моргає)

**Готово, коли:** власник може вести повний щоденник кількох котів і отримує нагадування.

### Етап 4 — AI та фан (1–2 тижні)

- [x] Edge Function `ai-mood`: фото → настрій + підпис для сторіз (ключі тільки на сервері; Claude Haiku 5.5)
- [x] Екран «Настрій дня» + генерація підпису (картка вгорі стрічки й настрій під кожним фото)
- [x] Шеринг картки в Instagram / Telegram (картинка 9:16 через системне «Поділитися»; у web — текст)
- [x] Онбординг «Познайомся з котом»: 5 питань з картинками → «тип характеру» + картка для шерингу ще до реєстрації
- [x] Перше фото → одразу AI-настрій (вау-ефект за 10 секунд)
- [x] Ліміт Free: 3 AI-фото на тиждень (`ai_usage`), кешування результатів

**Готово, коли:** новий користувач за хвилину отримує тип характеру і AI-настрій; ліміти працюють на сервері.

### Етап 5 — Монетизація й переклади (1 тиждень)

- [ ] RevenueCat: продукти (місяць / рік / назавжди), відновлення покупок, статус у кабінеті
- [ ] Paywall: річний план першим з позначкою «−40%», 7 днів безкоштовно лише на річний
- [ ] Тригери paywall: другий кіт, вичерпано AI-фото, експорт медкарти — **не на першому екрані**
- [ ] Ціни:
  - Android та iOS з Small Business Program: 79 ₴ / 549 ₴ / 1 290 ₴; $2.99 / $19.99 / $39.99
  - iOS без SBP: 99 ₴ / 699 ₴ / 1 590 ₴; $3.49 / $23.99 / $49.99 (найближча цінова сходинка Apple)
- [ ] Переклади pl, de, es (без російської) з перевіркою носіями мови
- [ ] Політика конфіденційності та умови використання

**Готово, коли:** покупка й відновлення працюють у sandbox обох сторів; усі 5 мов повні.

## 7. Після MVP (v2+)

### Пріоритет 1 — утримання і найцінніше

- [ ] «Рік тому сьогодні»

## 8. Принципи продукту

- Безпека тварини ніколи не за пейволом.
- Жодних діагнозів — максимум «варто показати ветеринару».
- Не засипати push; одне ранкове замість п'яти.
- Не тиснути на провину («Мася сумує без тебе» — ні).
- Без пейволу на першому екрані й без реклами.
